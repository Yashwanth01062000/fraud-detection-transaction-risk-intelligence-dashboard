# Fraud Detection & Transaction Risk Intelligence Dashboard

## Overview

This Power BI dashboard analyzes fraudulent transaction patterns, risk exposure, transaction channels, payment methods, and regional fraud trends.

## Dashboard Preview

![Dashboard](dashboard-overview.png)

## Business Problem

Financial institutions lose millions due to fraudulent transactions. This dashboard helps identify fraud patterns, monitor risk indicators, and support fraud prevention strategies.

## Key KPIs

- Total Transactions
- Fraud Transactions
- Fraud Rate %
- Total Fraud Amount

## Visualizations

- Fraud Distribution by Transaction Type
- Fraud Distribution by Payment Method
- Fraud Risk by Region
- Fraud Trend Analysis
- Fraud Count by Transaction Amount
- Transaction Channel Risk Analysis

- Power BI

- Data Modeling

## Business Impact

Provides fraud monitoring insights that help organizations identify high-risk transactions and reduce financial losses.
